# AllToolkit V4

A responsive, privacy-first Next.js toolkit with 120 browser-based tools.

## Run locally

```bash
npm install
npm run dev
```

## Production check

```bash
npm run build
```

Set `NEXT_PUBLIC_SITE_URL` in `.env.local` before deployment so canonical URLs and the sitemap use your real domain.

## PDF Suite Expansion
This build adds 12 browser-based PDF tools: split every N pages, rotate selected pages, insert PDF, swap pages, normalize page sizes, add margins, extract landscape pages, extract portrait pages, extract first/last pages, remove first/last pages, repeat a PDF, and extract a continuous page range.
